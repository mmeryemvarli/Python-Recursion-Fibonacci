# Python-Recursion-Fibonacci
Python implementations and performance comparisons of recursive and iterative algorithms, including Fibonacci, factorials, and search steps.

# Fundamental Algorithms & Recursion

This repository explores recursion, iterative approaches, time/space complexity analysis, and basic search/math routines in Python.

## Topics & Implementations

- **Fibonacci Numbers:** Comparing recursive $O(2^n)$ vs. iterative $O(n)$ implementations.
- **Summation ($1$ to $n$):** Demonstrating time vs. auxiliary space trade-offs between call stacks and iterative variables.
- **Linear Search:** Tracking step counts across best, average, and worst-case scenarios.
- **Factorial:** Comparing `while`-loop based iteration with recursive call stacks.
